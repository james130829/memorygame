# Memory Game

Pygame을 이용하여 제작한 숫자 기억력 게임입니다.

## 프로젝트 소개

게임이 시작되면 화면에 숫자가 잠시 표시됩니다.
플레이어는 숫자의 위치를 기억한 뒤, 숫자가 가려지면 1부터 순서대로 클릭해야 합니다.

정답을 모두 맞히면 다음 레벨로 진행되며, 레벨이 올라갈수록 기억해야 하는 숫자의 개수가 증가합니다.

## 주요 기능

* 숫자 랜덤 배치
* 레벨별 난이도 증가
* 제한 시간 후 숫자 숨김 처리
* 올바른 순서 클릭 판정
* 오답 선택 시 게임 종료
* 레벨 클리어 시 다음 단계 진행

## 개발 환경

* Python
* Pygame

## 실행 방법

1. Pygame 설치

```bash
pip install pygame
```

2. 프로젝트 실행

```bash
python memory_game.py
```

## 게임 방법

1. 시작 버튼을 클릭한다.<img width="1575" height="855" alt="Image" src="https://github.com/user-attachments/assets/7db81eb1-1c9c-42f5-9e94-b3e5d252072c" />
2. 화면에 표시된 숫자의 위치를 기억한다.
3. 숫자가 사라지면 1부터 순서대로 클릭한다.
4. 모든 숫자를 맞추면 다음 레벨로 진행된다.
5. 잘못된 숫자를 클릭하면 게임이 종료된다.

## 배운 점

이 프로젝트를 통해 Pygame의 화면 구성, 이벤트 처리, 랜덤 배치, 게임 로직 구현 방법을 학습할 수 있었다. 또한 레벨 시스템을 적용하여 난이도가 점진적으로 증가하는 게임을 구현하였다.
